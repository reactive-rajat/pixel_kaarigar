01 Overview

Most portfolio templates are static, hardcoded, and forgettable. Changing your name means hunting through JSX files. Updating a project card means touching five different components.


Obsidian flips this. All content lives in a single JSON config file. Edit your name, bio, skills, and projects in one place — the entire site updates instantly.


Beyond the architecture, Obsidian is built to feel premium. Each page has its own accent color. Glow effects create real atmospheric lighting — not flat CSS shadows. The kind of portfolio that makes recruiters stop scrolling.

02 Key Features
🗂
JSON-Driven Content System
All personal info, projects, skills, and contact details live in one config file. No HTML or JSX to touch — ever. Edit once, entire site updates.
🎨
Per-Page Color Themes
Every page has its own accent — purple, cyan, orange, green. Buttons, glows, borders, and icons all follow that page's color automatically.
⚙️
Global Color Config
One file controls the entire palette. Change your brand color in seconds — every element across all pages updates site-wide.
💡
Atmospheric Glow Effects
Not flat box-shadows. Real ambient lighting — cards emit light that bleeds into the dark background like a lamp in a dark room. Hover effects included.
